# Dynamic discovery and contradiction search

Production starts with an objective. Query strategies ask for economic signals (spending, transitions,
constraints, technical demand) and relationships (suppliers, customers, products, competitors,
complements, investors and portfolios), not predetermined sectors or logos. Later passes extend or
challenge actually discovered names. Company field researchers have distinct capital, talent,
product, internal-substitute, blind-spot, buyer and skeptical strategies.

Each research round evaluates missing/weak fields, orders them by configured priorities or a simple
uncertainty heuristic, issues support/independent/negative angles, opens results, validates claims,
records evidence, spawns eligible related entities and re-evaluates the contract. Query-budget rotation
prevents a permanently weak first field from starving all later fields. Max rounds is a budget, not
completion. This heuristic is not a calibrated monetary value-of-information model.

Entity proposals need accepted credible fact IDs, a canonical name and explicit Event #1 relevance.
Names and canonical URLs form deduplication keys; evidence IDs merge into an existing node.
EconomicGraph stores entities and recognized relationship edges with source provenance. Exact aliases
are supported; ambiguous corporate ownership/brand/entity resolution still needs review.

Stop reasons distinguish duplicates, weak evidence, low relevance/VOI, dependency hops and node
budget. Related links never create required-child recursion. A discovery sweep is saturated only
after configured consecutive successful passes predominantly yield no eligible new entities. No
retrieval capability, no credible evidence, errors or exhausted resource ceilings cannot masquerade
as saturation. Saturation is local diminishing yield, not proof of exhaustive coverage.

Every negative search is recorded, including a legitimate search with no results. Found opposing
claims are preserved. Independent red team uses a separately supplied executor instance, attacks
13 decision dimensions and reopens affected upstream owners and downstream dependencies. A separate
instance enables independent review but does not prove organizational/model independence; configure
and audit that property in production.
