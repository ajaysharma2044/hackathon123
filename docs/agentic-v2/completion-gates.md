# Deterministic completion gates

Each field has permitted epistemic statuses, source quality, minimum claims and optional profile
conditions. Company requirements cover identity, initiative, finances, business/product, strategic
need, internal capability, incremental value, answerable question, buyer, substitute, event value
chain, talent status, cohort, natural activity, artifact, decision, strongest objection, budget and
WTP status. Developer need applies only to the explicit developer profile. Budget/talent/WTP can be
explicit UNKNOWN; they do not become positive findings.

Every required field needs multiple executed search angles. Each node needs an executed negative
search plus configured primary and independent source coverage. Mere contradictory-claim IDs or a
sentence saying “searched” are insufficient. Contradictions block promotion; no silent averaging.
Runtime checks and graph transitions independently enforce the contract, including parent rollup.

Other contracts cover economic/problem/product/investor/technology/company-unit/buyer entities,
Cornell capability, costs, attendance, capacity, pricing, theme comparison and independent red team.
Unsupported types cannot resolve. Theme dimensions include participant, technical, company,
research, R&D, recruiting, repeatability and founder value; burden, privacy, contamination,
complexity and conflict. No default winning weights exist.

R&D requires positive evidence-backed assessments of uncertainty, parallelizability, prototypeability,
evaluation, student fit, failure information, researched internal substitute, IP and participant value.
It also validates the structured plan through the existing RDProblem/rd_fit kernel.
Data/qualitative plans require natural activity, consented capture, burden, a question, buyer relevance,
valid/invalid inference, generalizability limits, contamination and deliverable.

The existing rd_fit thresholds are structural feasibility heuristics, not estimates of sponsorship
revenue or event ranking weights. Plan validation is not participant consent or permission to collect.
